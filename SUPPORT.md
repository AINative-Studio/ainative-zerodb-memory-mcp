# Support

Thanks for using `ainative-zerodb-memory-mcp`! Here's how to get help.

## Documentation

Start with the [README](./README.md) for setup and the full 18-tool reference, and [AGENTS.md](./AGENTS.md) for the project structure and conventions if you're contributing code.

## Reporting a bug or requesting a feature

Open an issue in this repo's tracker:
[github.com/AINative-Studio/ainative-zerodb-memory-mcp/issues](https://github.com/AINative-Studio/ainative-zerodb-memory-mcp/issues).

Before filing, please check whether an existing open issue already covers it. For a bug, include:

- The package version (`npm ls ainative-zerodb-memory-mcp`)
- Your Node.js version and MCP client (Claude Desktop, Claude Code, Cody, etc.)
- The exact tool call and arguments that failed
- The full error output, not just the last line
